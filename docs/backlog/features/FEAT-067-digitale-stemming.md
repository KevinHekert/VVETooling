- Stem interface voor eigenaren

- Quorum indicator

- Conform splitsingsreglement
- Stemrecht per aandeel/breukdeel

## Acceptatiecriteria
- Stemming kan worden aangemaakt
- Eigenaren kunnen digitaal stemmen
- Stemrecht wordt correct berekend
- Quorum wordt automatisch gevalideerd
