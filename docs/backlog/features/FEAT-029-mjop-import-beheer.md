# FEAT-029: MJOP Import & Beheer

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Geneste nummering**: 14.1

## Functioneel doel
MJOP-gegevens kunnen worden geïmporteerd of handmatig ingevoerd, met overzicht van alle onderhoudsmomenten en kostenramingen.

## UX-impact
- Import wizard voor Excel/PDF MJOP's
- Handmatige invoer formulieren
- Overzichtspagina met alle onderhoudsmomenten
- Timeline view van geplande werkzaamheden

## Constraints
- Ondersteunde formaten: Excel (xlsx), PDF (OCR)
- Validatie van geïmporteerde data vereist

## Acceptatiecriteria
- MJOP kan worden geïmporteerd vanuit Excel
- Onderhoudsmomenten kunnen handmatig worden toegevoegd
- Timeline view toont planning over meerdere jaren
- Kostenramingen per onderhoudselement zijn zichtbaar
