# FEAT-021: Financieel dashboard & KPI's

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: Draft
- **Versie**: 1.0

## Functioneel doel
Penningmeester en bestuur krijgen een financieel dashboard met KPI's en managementsamenvattingen.

## UX-impact
- KPI-cards voor saldo, reserves, openstaande posten.
- PDF export van maandrapportage.

## Constraints
- Read-only voor bestuur en bewoners.
- KPI-definities vastleggen met finance team.

## Acceptatiecriteria
- Dashboard toont minimaal 5 kern-KPI's per VVE.
- Export levert managementsamenvatting in PDF.
