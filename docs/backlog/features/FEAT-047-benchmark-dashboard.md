- **Status**: ⬜ Backlog

## Functioneel doel
Dashboard met vergelijking van VVE-prestaties op kosten, reserves en onderhoud met soortgelijke VVE's.

## UX-impact
- Benchmark widget in dashboard
- Vergelijkingsgrafieken
- Ranking indicatoren
- Drill-down naar details

## Constraints
- Data geanonimiseerd
- Opt-in voor deelname aan benchmark

## Acceptatiecriteria
- Dashboard toont positie t.o.v. vergelijkbare VVE's
- Vergelijking op meerdere dimensies
- Trends over tijd zijn zichtbaar
- Aanbevelingen worden gegeven
