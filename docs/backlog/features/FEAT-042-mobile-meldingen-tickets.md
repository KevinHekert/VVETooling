# FEAT-042: Mobile Meldingen & Tickets

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Geneste nummering**: 18.2

## Functioneel doel
Eigenaren kunnen via mobiel defecten en issues melden met foto's en locatie, en de voortgang volgen.

## UX-impact
- Melding wizard met foto-upload
- Camera-integratie
- Ticket tijdlijn op mobiel
- Push notificaties voor updates

## Constraints
- Foto compressie voor upload
- Offline mode voor concept-meldingen

## Acceptatiecriteria
- Melding kan worden gemaakt met foto vanuit mobiel
- Locatie kan worden geselecteerd uit plattegrond
- Voortgang is zichtbaar in tijdlijn
- Notificatie bij statuswijziging
