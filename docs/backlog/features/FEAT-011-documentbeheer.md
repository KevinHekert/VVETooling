# FEAT-011: Documentbeheer

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ✅ Geïmplementeerd
- **Versie**: 1.1
- **Geneste nummering**: 6.1

## Functioneel doel
Bestuur kan documenten uploaden en organiseren; bewoners kunnen deze vinden en downloaden.

## UX-impact
- Documentlijst met filters en categorieën.
- Upload flow met status/toast.

## Constraints
- File type restricties en storage limits (D-004).
- Privacy by design.

## Acceptatiecriteria
- Upload van toegestane bestandsformaten.
- Documenten zichtbaar per rol.
