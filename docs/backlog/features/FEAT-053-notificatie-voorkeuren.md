# FEAT-053: Notificatie Voorkeuren

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Geneste nummering**: 22.2

## Functioneel doel
Gebruikers kunnen notificatie-voorkeuren instellen per kanaal en type bericht.

## UX-impact
- Voorkeuren settings pagina
- Per-type toggles (email, push, SMS)
- Digest opties (dagelijks, wekelijks)
- Test notificatie functie

## Constraints
- Kritieke notificaties niet uitschakelbaar
- Standaard voorkeuren per rol

## Acceptatiecriteria
- Voorkeuren kunnen worden ingesteld per type
- Kanaal kan worden gekozen per notificatie-type
- Digest frequentie kan worden ingesteld
- Test notificatie kan worden verstuurd
