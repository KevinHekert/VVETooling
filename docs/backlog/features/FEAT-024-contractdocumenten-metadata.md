# FEAT-024: Contractdocumenten & metadata

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: Draft
- **Versie**: 1.0

## Functioneel doel
Contracten worden opgeslagen met metadata (looptijd, opzegtermijn, leverancier, categorie).

## UX-impact
- Upload met verplichte metadata velden.
- Filter op leverancier en einddatum.

## Constraints
- Metadata verplicht bij upload.
- Alleen bestuur kan contractmetadata wijzigen.

## Acceptatiecriteria
- Contractupload vraagt om looptijd, opzegtermijn en leverancier.
- Overzicht toont contractstatus (actief/aflopend).
