# FEAT-009: Rol-specifieke dashboards

## Documentinformatie
- **Datum**: 2026-01-26
- **Eigenaar**: Product Owner
- **Status**: Ready
- **Versie**: 1.0

## Functioneel doel
Iedere rol ziet een passend dashboard met relevante informatie.

## UX-impact
- Beheerder: uitgebreid financieel overzicht.
- Bestuur: read-only overzicht met KPI’s.
- Bewoner: mobile-first beperkte info.

## Constraints
- Role-based UI verschillen (UX-02).
- Mobile-first voor bewoners (UX-03).

## Acceptatiecriteria
- Rolgebaseerde navigatie en content.
- Geen bewerk-knoppen voor read-only rollen.
