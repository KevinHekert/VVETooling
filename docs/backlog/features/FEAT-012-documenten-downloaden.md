# FEAT-012: Documenten inzien & downloaden

## Documentinformatie
- **Datum**: 2026-01-26
- **Eigenaar**: Product Owner
- **Status**: Ready
- **Versie**: 1.0

## Functioneel doel
Gebruikers kunnen documenten vinden, previewen en downloaden.

## UX-impact
- Inline previews waar mogelijk.
- Download actie met toast feedback.

## Constraints
- Performance bij grote bestanden.
- Access control per rol.

## Acceptatiecriteria
- Download binnen 5s voor standaard documenten.
- Bewoner ziet alleen toegestane documenten.
