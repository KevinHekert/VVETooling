# FEAT-035: Compliance Dashboard

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Geneste nummering**: 16.1

## Functioneel doel
Overzicht van alle compliance-verplichtingen met status, deadlines en alerts, zodat VVE's voldoen aan wettelijke eisen.

## UX-impact
- Dashboard met compliance-status per categorie
- Checklist met verplichtingen
- Alert-indicatoren voor deadlines
- Drill-down naar details per verplichting

## Constraints
- Categorieën: KvK, verzekeringen, reservefonds, AVG, ALV
- Updates bij wetswijzigingen

## Acceptatiecriteria
- Dashboard toont status per compliance-categorie
- Alerts worden gegenereerd voor naderende deadlines
- Checklists kunnen worden afgevinkt
- Historische compliance is inzichtelijk
