# FEAT-043: Mobile Stemmen & Polls

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Geneste nummering**: 18.3

## Functioneel doel
Eigenaren kunnen via mobiel stemmen op voorstellen en polls, zowel tijdens als buiten ALV's.

## UX-impact
- Stemming interface op mobiel
- Live resultaten view
- Poll notificaties
- Stemhistorie

## Constraints
- Authenticatie vereist voor stemmen
- Eén stem per eigendomsrecht

## Acceptatiecriteria
- Eigenaar kan stemmen via mobiele app
- Resultaten worden real-time getoond (na afsluiting)
- Notificatie wordt verstuurd bij nieuwe poll
- Stemhistorie is inzichtelijk
