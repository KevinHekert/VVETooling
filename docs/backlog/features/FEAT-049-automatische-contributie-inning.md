# FEAT-049: Automatische Contributie-inning

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Geneste nummering**: 21.1

## Functioneel doel
Automatische inning van contributies via iDEAL of SEPA-incasso met reconciliatie.

## UX-impact
- Betaalmethode selectie per eigenaar
- Automatische incasso setup
- Betaalstatus overzicht
- Reconciliatie dashboard

## Constraints
- PSD2 compliance
- SEPA mandaat vereist voor incasso

## Acceptatiecriteria
- Eigenaar kan betaalmethode kiezen
- Automatische incasso kan worden ingesteld
- Betalingen worden automatisch gematcht
- Betaalstatus per eigenaar is zichtbaar
