# STORY-003: Bewoner ziet eigen betalingsstatus

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ✅ Geïmplementeerd
- **Versie**: 1.1
- **Geneste nummering**: 2.2.1

## User story
Als **bewoner** wil ik mijn eigen betalingsstatus zien, zodat ik weet of mijn contributie op orde is.

## Acceptatiecriteria
- Bewoner ziet alleen eigen status (geen andere bewoners).
- Status is zichtbaar op mobile-first dashboard.
- Meldingen zijn niet-blokkerend (toast/inline).

## UX/UI aandachtspunten
- Mobile-first layout (max 3-4 items).
- Inline status indicatoren.
