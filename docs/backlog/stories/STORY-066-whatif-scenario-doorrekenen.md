# STORY-066: What-if scenario doorrekenen

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ✅ Geïmplementeerd
- **Versie**: 1.0
- **Prioriteit**: Could (Horizon 2)

## User story
Als **penningmeester** wil ik what-if scenario's kunnen doorrekenen met verschillende contributiehoogtes, zodat ik de impact op reserves kan presenteren aan de ALV.

## Acceptatiecriteria
- Input: nieuwe contributie per eigenaar
- Output: aangepaste reserve-prognose grafiek
- Vergelijking huidige vs scenario
- Scenario kan worden opgeslagen voor presentatie

## UX/UI aandachtspunten
- Slider voor contributie-aanpassing
- Real-time update van grafiek
- Export naar PDF voor ALV
