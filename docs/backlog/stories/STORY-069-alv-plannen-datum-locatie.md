# STORY-069: ALV plannen met datum en locatie

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ✅ Geïmplementeerd
- **Versie**: 1.0
- **Prioriteit**: Must (Horizon 2)
- **Geneste nummering**: 15.1.1

## User story
Als **secretaris** wil ik een ALV kunnen plannen met datum, tijd, locatie en type (fysiek/online/hybride), zodat eigenaren tijdig worden geïnformeerd.

## Acceptatiecriteria
- Datum en tijd selecteerbaar
- Locatie: fysiek adres of videoconference link
- Type: fysiek, online, hybride
- Validatie dat datum minimaal 8 dagen in de toekomst ligt

## UX/UI aandachtspunten
- Kalender picker
- Toggle voor type vergadering
- Adres input of link input afhankelijk van type
