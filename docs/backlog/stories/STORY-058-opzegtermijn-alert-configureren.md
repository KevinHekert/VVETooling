# STORY-058: Opzegtermijn alert configureren

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ✅ Geïmplementeerd
- **Versie**: 1.0
- **Prioriteit**: Should (Horizon 2)
- **Geneste nummering**: 13.2.1

## User story
Als **beheerder** wil ik kunnen instellen hoeveel dagen voor de opzegtermijn ik een alert ontvang, zodat ik tijdig actie kan ondernemen.

## Acceptatiecriteria
- Alert-termijn configureerbaar per contract (30, 60, 90 dagen)
- Standaardinstelling op VVE-niveau instelbaar
- Alert wordt gegenereerd op ingestelde datum
- Alert is zichtbaar in dashboard en per email

## UX/UI aandachtspunten
- Dropdown voor alert-termijn selectie
- Preview van alert-datum
- Bevestiging bij opslaan
