## User story
Als **secretaris** wil ik alerts ontvangen voor naderende compliance deadlines, zodat we geen verplichtingen missen.

## Acceptatiecriteria
- Alert voor: jaarlijkse ALV, KvK update, verzekering verlenging
- Configureerbare termijnen (30, 60, 90 dagen)
- Alert via email en dashboard
- Link naar betreffende compliance-item

## UX/UI aandachtspunten

- Urgentie kleuren
- Direct action links
