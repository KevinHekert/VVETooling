## User story
Als **eigenaar** wil ik push notificaties ontvangen voor belangrijke updates, zodat ik direct op de hoogte ben.

## Acceptatiecriteria
- Push werkt in browser en PWA
- Notificatie bevat titel en korte tekst
- Klik op notificatie opent relevante pagina
- Opt-in vereist bij eerste gebruik

## UX/UI aandachtspunten
- Native push interface
- Permission dialog uitleg
- Notificatie centrum in app
