## User story
Als **beheerder** wil ik een bestaand MJOP vanuit Excel kunnen importeren, zodat ik bestaande planningen niet opnieuw hoef in te voeren.

## Acceptatiecriteria
- Excel upload (.xlsx) ondersteund
- Wizard voor kolom-mapping
- Preview van geïmporteerde data voor bevestiging
- Validatie met foutmeldingen per rij

## UX/UI aandachtspunten
- Stappen-wizard voor import
- Duidelijke mapping interface
- Error overzicht met regel-nummers
