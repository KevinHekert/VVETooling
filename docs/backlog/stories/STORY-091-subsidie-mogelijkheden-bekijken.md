## User story
Als **penningmeester** wil ik kunnen zien welke subsidies beschikbaar zijn voor onze VVE, zodat we maximaal gebruik maken van beschikbare financiering.

## Acceptatiecriteria
- Overzicht van beschikbare subsidies (SVVE, ISDE, SCE)
- Filter op type maatregel
- Indicatie van bedrag/percentage vergoeding
- Link naar officiële aanvraagpagina

## UX/UI aandachtspunten

- Filter chips
- External link icoon
