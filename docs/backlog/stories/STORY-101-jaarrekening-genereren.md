## User story
Als **penningmeester** wil ik een jaarrekening kunnen genereren in standaardformaat, zodat deze kan worden gepresenteerd op de ALV.

## Acceptatiecriteria
- Automatische samenstelling uit financiële data
- Balans en resultatenrekening
- Vergelijking met vorig jaar
- Export naar PDF

## UX/UI aandachtspunten

- Preview in browser
- Download knop prominent
