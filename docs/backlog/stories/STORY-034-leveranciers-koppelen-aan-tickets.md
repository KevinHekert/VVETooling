# STORY-034: Leveranciers koppelen aan tickets

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Prioriteit**: Should (Horizon 2)
- **Geneste nummering**: 10.2.1

## User story
Als **bestuurslid** wil ik leveranciers aan tickets kunnen koppelen, zodat opvolging en communicatie centraal beschikbaar zijn.

## Acceptatiecriteria
- Bestuur kan leverancier selecteren vanuit ticketdetail.
- Tijdlijn toont toegewezen leverancier met contactinfo.
- Overzicht ondersteunt filteren op leverancier.

## UX/UI aandachtspunten
- Gebruik select/dropdown component met zoekfunctie.
- Leveranciersbadge in ticket-lijst.
- Inline feedback bij koppeling.
