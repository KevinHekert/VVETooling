# STORY-114: Stem uitbrengen op voorstel

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Prioriteit**: Must (Horizon 2)
- **Geneste nummering**: 27.1.2

## User story
Als **eigenaar** wil ik mijn stem kunnen uitbrengen op een actief voorstel, zodat mijn mening meetelt in de besluitvorming.

## Acceptatiecriteria
- Stem opties zichtbaar (voor, tegen, blanco)
- Eén stem per eigendomsrecht
- Bevestiging voor definitief stemmen
- Stem kan niet worden gewijzigd na uitbrengen

## UX/UI aandachtspunten
- Duidelijke knoppen per optie
- Bevestiging dialog
- Success toast na stemmen
