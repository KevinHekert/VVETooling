# STORY-068: Onderhoudstaak status bijwerken

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Prioriteit**: Should (Horizon 2)
- **Geneste nummering**: 14.3.2

## User story
Als **verantwoordelijke** wil ik de status van een onderhoudstaak kunnen bijwerken met notities, zodat de voortgang zichtbaar is voor het bestuur.

## Acceptatiecriteria
- Status flow: gepland → in uitvoering → afgerond
- Notitie toevoegen bij statuswijziging
- Datum van wijziging wordt gelogd
- Notificatie naar aanmaker bij voltooiing

## UX/UI aandachtspunten
- Kanban-style drag & drop optie
- Status dropdown met verplichte notitie
- Historie van statuswijzigingen
