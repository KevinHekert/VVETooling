# STORY-085: Mobile portal documenten inzien

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Prioriteit**: Should (Horizon 2)

## User story
Als **eigenaar** wil ik via mijn mobiel documenten kunnen inzien en downloaden, zodat ik altijd toegang heb tot belangrijke VVE-informatie.

## Acceptatiecriteria
- Document bibliotheek toegankelijk via mobiel
- Documenten kunnen worden bekeken in-app
- Download naar device mogelijk
- Recent bekeken documenten worden getoond

## UX/UI aandachtspunten
- Touch-optimized lijst
- PDF viewer in-app
- Offline caching van recente documenten
