## Documentinformatie
- **Datum**: 2026-01-27

## User story
Als **beheerder** wil ik proactieve alerts ontvangen over mogelijke issues (lage reserves, aflopende contracten), zodat ik preventief kan handelen.

## Acceptatiecriteria
- Alerts voor: lage reserves, aflopende contracten, onbetaalde contributies
- Alert bevat onderbouwing en aanbevolen actie
- Alerts zichtbaar in dashboard en per email
- Alert kan worden genegeerd met reden

## UX/UI aandachtspunten
- Insights panel in dashboard
- Kleurcodering op urgentie
- Actie buttons per alert
