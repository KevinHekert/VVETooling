# STORY-089: Mobile stemmen op poll

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Prioriteit**: Should (Horizon 2)
- **Geneste nummering**: 18.3.1

## User story
Als **eigenaar** wil ik via mijn mobiel kunnen stemmen op een poll, zodat ik mijn stem kan uitbrengen ook als ik niet thuis ben.

## Acceptatiecriteria
- Actieve polls zichtbaar in app
- Stem uitbrengen met bevestiging
- Resultaten zichtbaar na afsluiting
- Push notificatie bij nieuwe poll

## UX/UI aandachtspunten
- Grote tap targets voor stemopties
- Bevestiging voor definitief stemmen
- Resultaten grafiek na afsluiting
