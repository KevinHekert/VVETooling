## Documentinformatie

- **Status**: ✅ Geïmplementeerd

## User story
Als **eigenaar** wil ik mijn notificatie-voorkeuren kunnen instellen per kanaal en type, zodat ik alleen relevante berichten ontvang.

## Acceptatiecriteria
- Toggle per notificatie-type (ALV, betalingen, onderhoud)
- Kanaal selectie per type (email, push, SMS)
- Digest optie (direct, dagelijks, wekelijks)
- Test notificatie functie

## UX/UI aandachtspunten
- Matrix van type vs kanaal
- Clear toggles
- Save bevestiging
