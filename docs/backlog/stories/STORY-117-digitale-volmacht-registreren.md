# STORY-117: Digitale volmacht registreren

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ✅ Geïmplementeerd
- **Versie**: 1.0
- **Prioriteit**: Must (Horizon 2)
- **Geneste nummering**: 27.3.1

## User story
Als **eigenaar** wil ik digitaal een volmacht kunnen geven aan een andere eigenaar, zodat mijn stem meetelt als ik niet aanwezig kan zijn.

## Acceptatiecriteria
- Selectie van gevolmachtigde uit eigenaren-lijst
- Koppeling aan specifieke vergadering
- Bevestiging naar beide partijen
- Volmacht zichtbaar in quorum-berekening

## UX/UI aandachtspunten
- Autocomplete voor gevolmachtigde
- Vergadering selectie
- Bevestiging dialog
