## User story
Als **beheerder** wil ik een API key kunnen aanmaken voor externe integraties, zodat systemen veilig data kunnen uitwisselen.

## Acceptatiecriteria
- API key genereren met beschrijving
- Permissions per key instelbaar
- Key tonen alleen bij aanmaak
- Key intrekken mogelijk

## UX/UI aandachtspunten
- Copy-to-clipboard voor key
- Warning dat key eenmalig zichtbaar is
- Actieve keys overzicht
