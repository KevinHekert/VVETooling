# STORY-086: Mobile contributiestatus bekijken

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Prioriteit**: Should (Horizon 2)
- **Geneste nummering**: 18.1.2

## User story
Als **eigenaar** wil ik mijn contributiestatus kunnen bekijken op mijn mobiel, zodat ik weet of ik bij ben met betalingen.

## Acceptatiecriteria
- Overzicht van betaalde en openstaande contributies
- Bedrag en datum per betaling
- Status indicator (op tijd, achterstallig)
- Link naar betalen indien openstaand

## UX/UI aandachtspunten
- Duidelijke status kleuren
- Compacte betalingshistorie
- Betaal-knop prominent bij openstaand
