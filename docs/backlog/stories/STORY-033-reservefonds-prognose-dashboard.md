# STORY-033: Reservefonds prognose dashboard

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: Draft
- **Versie**: 0.1
- **Prioriteit**: Should (Horizon 2)

## User story
Als **bestuurslid** wil ik duidelijke prognoses van groei/afname van het reservefonds zien, zodat ik onderhoud en budgetten kan plannen.

## Acceptatiecriteria
- Dashboard toont prognosekaarten per reserve met trendindicator.
- Bestuur kan scenario’s selecteren (basis/optimistisch/conservatief).
- Export bevat prognosegegevens per periode.

## UX/UI aandachtspunten
- Grafiek met duidelijke legend en hover-details.
- Mobile: compacte kaarten, grafiek scrolbaar.
- Inline toelichting via info tooltip.
