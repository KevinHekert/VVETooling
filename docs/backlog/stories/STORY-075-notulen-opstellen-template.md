# STORY-075: Notulen opstellen met template

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Prioriteit**: Must (Horizon 2)
- **Geneste nummering**: 15.3.1

## User story
Als **secretaris** wil ik notulen kunnen opstellen met een template dat automatisch de agenda en aanwezigen bevat, zodat ik efficiënt kan notuleren.

## Acceptatiecriteria
- Template bevat automatisch: datum, aanwezigen, agenda
- Rich text editor voor vrije invoer
- Markeren van besluiten en actiepunten
- Auto-save functionaliteit

## UX/UI aandachtspunten
- WYSIWYG editor
- Highlight functie voor besluiten
- Sticky toolbar
