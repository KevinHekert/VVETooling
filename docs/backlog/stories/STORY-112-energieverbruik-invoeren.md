# STORY-112: Energieverbruik invoeren

## Documentinformatie
- **Datum**: 2026-01-27
- **Eigenaar**: Product Owner
- **Status**: ⬜ Backlog
- **Versie**: 1.0
- **Prioriteit**: Could (Horizon 2)

## User story
Als **penningmeester** wil ik het gemeenschappelijk energieverbruik kunnen invoeren per periode, zodat we inzicht krijgen in trends.

## Acceptatiecriteria
- Invoer van verbruik (kWh, m³ gas) per maand
- Vergelijking met vorige periode automatisch
- Kosten berekening op basis van tarief
- Grafiek met verbruik over tijd

## UX/UI aandachtspunten
- Input per meter type
- Trend pijl (stijging/daling)
- Grafiek met periode selectie
