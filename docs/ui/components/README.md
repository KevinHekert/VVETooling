## Algemene uitgangspunten
- Componenten volgen de design tokens (kleur, typografie, spacing) uit het Design System.
- Feedback is **niet-blokkerend**, **tijdelijk** en **contextueel** waar mogelijk.
- Elk component moet herleidbaar zijn naar UX-constraints (UX-04 performance, UX-05 accessibility).
